== Description ==
Muestra las valoraciones de Trustpilot en WordPress y Divi con un diseño personalizable y múltiples opciones de layout avanzadas.

**Características principales:**
* ⭐ **Estrellas de valoración** - Muestra la puntuación de cada reseña
* 🔗 **Reseñas clickeables** - Enlaces directos a Trustpilot
* 📅 **Fechas de reseñas** - Información temporal de las valoraciones
* 🎨 **5 layouts diferentes** - Grid, Lista, Carrusel, Masonry y Timeline
* 🎯 **Sistema de caché** - Mejora el rendimiento y reduce solicitudes
* 🎨 **Múltiples estilos** - Moderno, Clásico, Minimalista, Elegante y Audaz
* 🌈 **6 esquemas de colores** - Personaliza la apariencia visual
* 📱 **Diseño responsive** - Optimizado para todos los dispositivos
* ⚡ **Módulo nativo para Divi** - Integración perfecta con Divi
* 🔧 **Configuración avanzada** - Panel de administración completo

**Nuevas características en la versión 1.7:**
* ⭐ **Sistema de estrellas** - Extrae y muestra automáticamente las valoraciones
* 🔗 **Reseñas clickeables** - Click en cualquier reseña te lleva a Trustpilot
* 📅 **Fechas automáticas** - Extrae y muestra las fechas de las reseñas
* 🏗️ **Layout Masonry** - Diseño tipo Pinterest con columnas configurables
* ⏰ **Layout Timeline** - Línea de tiempo vertical con marcadores
* 🎨 **Estilos de tarjetas** - 5 estilos diferentes para personalizar

* 📱 **Responsive mejorado** - Adaptación perfecta a móviles y tablets
* ♿ **Accesibilidad** - Mejoras en navegación por teclado y lectores

== Installation ==
1. Subir el plugin a la carpeta `/wp-content/plugins/` de tu instalación de WordPress.
2. Activar el plugin a través del menú 'Plugins' en WordPress.
3. Ir a 'Trustpilot Reviews' en el menú de administración.
4. Configurar la URL de Trustpilot y otras opciones.
5. Usar el shortcode `[custom_trustpilot_reviews]` en tus páginas o posts.

== Frequently Asked Questions ==
= ¿Cómo configuro la URL de Trustpilot? =
Ve a 'Trustpilot Reviews' > 'Configuración' en el panel de administración y ingresa la URL de la página de reseñas de tu empresa en Trustpilot.

= ¿Puedo cambiar el número de reseñas mostradas? =
Sí, puedes configurar el número de reseñas desde la configuración del plugin o usar el parámetro `count` en el shortcode.

= ¿Qué layouts están disponibles? =
El plugin ofrece 5 layouts: **Grid** (con opción de columnas), **Lista**, **Carrusel** con navegación, **Masonry** (tipo Pinterest) y **Timeline** (línea de tiempo).

= ¿Cómo uso el plugin con Divi? =
Si tienes Divi instalado, verás un nuevo módulo "Trustpilot Reviews" en el editor de Divi que puedes arrastrar y soltar en tus páginas.

= ¿El plugin tiene caché? =
Sí, incluye un sistema de caché configurable que mejora el rendimiento y reduce las solicitudes a Trustpilot.

= ¿Puedo hacer las reseñas clickeables? =
Sí, puedes habilitar esta opción desde la configuración para que al hacer click en una reseña se abra directamente en Trustpilot.

= ¿Se muestran las estrellas de valoración? =
Sí, el plugin extrae automáticamente las estrellas de cada reseña y las muestra visualmente.

= ¿Qué estilos de tarjetas hay disponibles? =
Dispones de 5 estilos: Moderno, Clásico, Minimalista, Elegante y Audaz, cada uno con su propia apariencia visual.
